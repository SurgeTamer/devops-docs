# DevOps Operations Handbook
Учебный сайт документации, собираемый из Markdown и публикуемый через GitHub
Actions.
**Версия: 1.** Этот маркер используется при исследовании неудачного выпуска.
## Контур поставки
1. Изменение предлагается через Pull Request.
2. Pylint проверяет Python-код.
3. После слияния в `main` MkDocs собирает статический сайт.
4. GitHub Pages публикует артефакт сборки.
Адрес будущего сайта: `https://SurgeTamer.github.io/devops-docs/`.
**Версия: 2.** Обновление после исправления ссылки.
## Восстановление
Перед восстановлением изучите [журнал типовых инцидентов](incidents.md).
Симптом: failed workflow Publish documentation после merge.
Затронутый компонент: сборка MkDocs, задание build.
Доказательство: сообщение о битой ссылке на docs/recovery.md.
Причина: ссылка указывает на несуществующий файл; --strict превращает
предупреждение в ошибку.
Влияние: новая версия не опубликована; предыдущая версия сайта остаётся доступной.
